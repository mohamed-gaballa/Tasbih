# 📿 Digital Tasbih

A simple digital Tasbih counter built using HTML, CSS, and JavaScript.

## ✨ Features
- Count Tasbih with a single click
- Reset the counter easily
- Simple and user-friendly interface
- Dark and modern design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎯 Project Goal
This project was created to practice front-end development and build an interactive web application.
